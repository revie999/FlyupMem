# Issue Tracker

**Platform:** GitHub Issues
**Repository:** `revie999/FlyupMem` (private)
**URL:** https://github.com/revie999/FlyupMem/issues

## How it works

- Issues are created and managed via `gh issue create`, `gh issue list`, `gh issue close`
- Labels are used for triage state (see `triage-labels.md`)
- PRs link to issues via `Closes #N` in commit messages

## Conventions

- Title format: `[component] brief description` (e.g. `[search] add temporal BFS`)
- Always apply a triage label when creating issues
- Use milestones for Phase tracking (Phase 1, Phase 2, etc.)
